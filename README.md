# Order App

A simple react application to create order with address

# features

- Create new orders using a form
- Fields included:
  - Customer Name
  - Phone Number
  - Address
  - Service Type (A, B)
  - Preferred Pickup Slot
- Display all created orders in a table
- Basic validation (Name & Phone required)
- Data stored in local state (no backend)

## 🛠️ Tech Stack

- React (Vite)
- JavaScript (ES6)
- Tailwind CSS (if used)
